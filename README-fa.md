## 🤔 چیکار می‌کنه؟

Copilot Chat وی‌‌اس‌کد معمولاً فقط مدل‌های خود مایکروسافت رو ارائه می‌ده.
**مدل‌های روتر** بهت اجازه می‌ده سرویس‌دهنده‌های خودت رو اضافه کنی و مدل‌های
**اون‌ها** رو توی همون چت استفاده کنی — مستقیم از همون انتخاب‌گر مدل معمولی.

**چرا عاشقش می‌شی:**

- 🔑 **چند کلید API رو همزمان استفاده کن** — چندتا کلید (رایگان) داری؟
  همه‌شون رو وارد کن. وقتی یکی به محدودیتش خورد، بعدی خودکار جایگزین می‌شه.
  دیگه خبری از وقفه‌های «محدودیت نرخ» نیست.
- ❄️ **بدون انتظار دستی** — اگر یک کلید به استراحت نیاز داشته باشه،
  افزونه زمان‌بندی رو مدیریت می‌کنه و خودش به کلید دیگه‌ای سوییچ می‌کنه.
- 🏠 **با هوش مصنوعی محلی هم کار می‌کنه** — از مدل‌هایی که روی کامپیوتر
  خودت اجرا می‌شن استفاده کن (Ollama، LM Studio) — اصلاً کلید لازم نیست.
- 📊 **ببین چه خبره** — یه نشانگر کوچیک توی نوار وضعیت، وضعیت کلیدهات رو
  یک‌نگاهی نشون می‌ده.
- 🔐 **کلیدهات امن می‌مونن** — توی حافظه امن وی‌‌اس‌کد ذخیره می‌شن، هرگز توی
  فایل‌های متنی ساده نه.
- 🧠 **با مدل‌های تفکری و ایجنت‌های ابزار-محور** از همین اول کار می‌کنه.

## 📦 نحوه نصب

### روش ۱ — از مارکت‌پلیس وی‌‌اس‌کد *(ساده‌ترین)*

1. وی‌‌اس‌کد رو باز کن
2. روی آیکون **Extensions** در نوار کناری چپ کلیک کن (یا `Ctrl+Shift+X` رو بزن)
3. دنبال **Router Models** بگرد
4. روی **Install** کلیک کن

یا این لینک رو توی مرورگرت باز کن و روی Install کلیک کن:
**<https://marketplace.visualstudio.com/items?itemName=alireza-yaghouti.router-models>**

### روش ۲ — دانلود فایل از گیت‌هاب

1. به صفحه **[Releases](https://github.com/web-elite/router-models/releases/latest)**
   برو و فایلی که آخرش **`.vsix`** داره رو دانلود کن
2. وی‌‌اس‌کد رو باز کن → روی آیکون **Extensions** کلیک کن (`Ctrl+Shift+X`)
3. روی **منوی ⋯** (بالای پنل Extensions) کلیک کن → **Install from VSIX…**
4. فایل دانلودشده رو انتخاب کن — تمام!

> [!TIP]
> با روش ۲، وی‌‌اس‌کد افزونه رو خودکار به‌روز نمی‌کنه. برای باخبر شدن از
> نسخه‌های جدید، توی صفحه گیت‌هاب روی **Watch → Custom → Releases** کلیک کن.

## 🚀 نحوه استفاده

1. `Ctrl+Shift+P` رو بزن و **Router Models: Add Provider** رو تایپ کن
2. فرم ساده رو پر کن:
   - **Name** — هرچی دوست داری، مثلاً `My OpenAI`
   - **Base URL** — آدرس سرویس‌دهنده (جدول زیر رو ببین)
   - **API keys** — یکی یا بیشتر، هرکدوم توی یه خط جدید
     *(برای Ollama / LM Studio محلی این رو خالی بذار)*
3. Copilot Chat رو باز کن، روی **انتخاب‌گر مدل** بالای چت کلیک کن — مدل‌های
   جدیدت زیر بخش **Router Models** هستن. یکی رو انتخاب کن و چت کن! 🎉

همچنین می‌تونی همه‌چیز رو از پنل **Router Models** در نوار فعالیت سمت چپ
مدیریت کنی — با دکمه‌های ساده سرویس‌دهنده اضافه، ویرایش یا حذف کن.

### 🌐 آدرس‌های پایه آماده کپی

| سرویس‌دهنده | Base URL |
| --- | --- |
| OpenAI | `https://api.openai.com/v1` |
| OpenRouter | `https://openrouter.ai/api/v1` |
| Groq | `https://api.groq.com/openai/v1` |
| Together AI | `https://api.together.xyz/v1` |
| Ollama *(روی کامپیوترت)* | `http://localhost:11434/v1` |
| LM Studio *(روی کامپیوترت)* | `http://localhost:1234/v1` |

هر سرویس دیگه‌ای که با فرمت «OpenAI» کار کنه هم جواب می‌ده.

## 🏷️ علامت‌گذاری مدل‌های رایگان (Free)

کنار هر مدل توی پنل **Router Models** یه دکمه کوچک **+ free** هست. روش
کلیک کن تا مدل به‌عنوان رایگان علامت بخوره:

- توی سایدبار یه تگ سبز **✓ free** کنار مدل دیده می‌شه،
- توی انتخاب‌گر مدل Copilot اسم مدل به شکل `Model name (free)` نشون داده
  می‌شه؛ پس توی کادر جستجوی انتخاب‌گر فقط بنویس **free** تا همه مدل‌های
  رایگان از همه سرویس‌دهنده‌ها یه‌جا لیست بشن،
- مدل‌هایی که خود id یا اسم‌شون کلمه «free» رو داره (مثل مدل‌های `:free`
  در OpenRouter) خودکار لیبل رایگان می‌گیرن،
- این علامت موقع رفرش کردن لیست مدل‌ها هم حفظ می‌شه.

برای برداشتن لیبل، همون دکمه رو دوباره بزن (الان **✓ free** نشون می‌ده).
فرم **+ Model** توی سایدبار و دستور `Router Models: Add Model Manually`
هم گزینه‌ی «free» رو دارن.

## 🎁 تشخیص خودکار مدل‌های رایگان

به‌جای علامت‌گذاری تک‌تک مدل‌ها، خود Router Models می‌تونه این کار رو
انجام بده. افزونه یه **لیست curated از مدل‌های رایگان** که توسط سازنده‌ی
افزونه نگه‌داری می‌شه رو دانلود می‌کنه، هر سرویس‌دهنده‌ای که اضافه کردی رو
**از طریق دامنه‌ی اصلی base URL** تطبیق می‌ده (یعنی `https://openrouter.ai/api/v1`
توی لیست با سرویس‌دهنده‌ای که به‌صورت `https://openrouter.ai/v1` اضافه‌ش
کرده‌ای هماهنگ می‌شه) و همه‌ی مدل‌های لیست‌شده رو خودکار رایگان علامت
می‌زنه.

این لیست یه خدمت‌ه که همراه خود افزونه ارائه می‌شه — نه چیزی برای هاست
کردن داره و نه آدرسی برای تنظیم کردن. این قابلیت **پیش‌فرض خاموشه** و تا
وقتی روشنش نکنی چیزی دانلود نمی‌شه.

**۱. روشنش کن.** توی پایین پنل سایدبار روی **Enable** کلیک کن، دکمه 🎁 توی
هدر سایدبار رو بزن، یا دستور **Router Models: Detect Free Models** رو اجرا
کن. می‌تونی تنظیمات `routerModels.freeModelsEnabled` رو هم عوض کنی.

**۲. همین.** بعدش افزونه:

- یه خط پایین پنل نشون می‌ده با تعداد مدل‌ها، تعداد سرویس‌دهنده‌ها،
  زمان گذشته از آخرین بروزرسانی و یه لینک **Update** برای دریافت دستی
  آخرین لیست،
- **هر `routerModels.freeModelsRefreshHours` ساعت (پیش‌فرض ۲۴ — می‌تونی
  عوضش کنی)** لیست رو دوباره دانلود می‌کنه،
- موقع استارتاپ هم، اگه نسخه‌ی کش‌شده قدیمی‌تر از بازه‌ی تنظیم‌شده باشه،
  یه بروزرسانی انجام می‌ده تا کامپیوتری که روز‌ها خاموش بوده هم هم‌خوان
  بشه.

مدلی که از لیست حذف بشه، دیگه رایگان نشون داده نمی‌شه؛ و علامت‌های دستی
**+ free** خودت هم کنارش به کارشون ادامه می‌دن.

برای کنجکاوها: لیست یه فایل ساده‌ی JSON هست که دامنه‌ی هر سرویس‌دهنده رو
به آیدی مدل‌های رایگانش وصل می‌کنه (الگوی glob هم پشتیبانی می‌شه، پس
`meta-llama/*` همه‌ی مدل‌های زیر این پیشوند رو رایگان نشون می‌ده):

```json
{
  "version": 1,
  "updated": "2025-01-30T12:00:00Z",
  "providers": [
    {
      "baseUrl": "https://openrouter.ai/api/v1",
      "freeModels": [
        "deepseek/deepseek-chat-v3:free",
        "qwen/qwen-2.5-72b-instruct:free",
        "meta-llama/*"
      ]
    },
    {
      "baseUrl": "https://api.deepseek.com",
      "freeModels": ["deepseek-chat", "deepseek-reasoner"]
    }
  ]
}
```

## 📥 ورود از فایل پشتیبان (9router، omnirouter یا هر فورکی از 9router)

1. دستور **`Router Models: Import Providers from JSON`** رو اجرا کن — یا
   روی دکمه ⇩ توی سایدبار کلیک کن.
2. فایل پشتیبان `.json` خودت رو انتخاب کن.
3. همین! همه سرویس‌دهنده‌ها و کلیدهای API موجود توی فایل خودکار اضافه
   می‌شن — کلیدهایی که از قبل داری رد می‌شن، پس چیزی تکراری نمی‌شه.
   لیست مدل‌ها هم خودش پر می‌شه.

---

## 📤 خروجی گرفتن (بکاپ و انتقال به یه کامپیوتر دیگه)

1. دستور **`Router Models: Export Providers to JSON`** رو اجرا کن — یا
   روی دکمه ⤒ توی هدر سایدبار کلیک کن.
2. انتخاب کن که **کلیدهای API** توی فایل باشن یا نه — *با کلیدها* یعنی
   فایل همه‌چیز رو کامل برمی‌گردونه (فایل رو خصوصی نگه دار!)، *بدون
   کلیدها* برای به اشتراک گذاشتن امنه.
3. فایل رو ذخیره کن. روی هر کامپیوتر دیگه با
   **`Router Models: Import Providers from JSON`** واردش کن — اونجا
   می‌تونی بین **Merge** (ادغام با تنظیمات فعلی) یا **Replace**
   (جایگزینی کامل) انتخاب کنی. آدرس سرویس‌ها، آیکون‌ها، cooldown ها،
   مدل‌های دستی، تگ‌های free و الگوهای include/exclude همه با هم
   منتقل می‌شن.

## ☁️ سینک خودکار شرکت ↔ خونه

Router Models با **VS Code Settings Sync** (اکانت GitHub یا Microsoft
تو) کار می‌کنه:

- کانفیگ سرویس‌دهنده‌ها، لیست مدل‌ها، مدل‌های دستی و تگ‌های free به
  صورت خودکار بین کامپیوترهات سینک می‌شن.
- کلیدهای API به‌صورت پیش‌فرض **سینک نمی‌شن** — هر کدوم توی حافظه امن
  همون کامپیوتر می‌مونن. برای اینکه کلیدها هم سینک بشن، تنظیم
  **`routerModels.syncApiKeys`** رو روی *هر دو* ماشین روشن کن (کلیدها
  داخل بکاپ رمزنگاری‌شده‌ی Settings Sync منتقل می‌شن).
- حتماً مطمئن شو که خود Settings Sync روشنه (آیکون چرخ‌دنده →
  *Backing up and Syncing…* → ورود با GitHub/Microsoft).
- بعد از سینک، سایدبار Router Models رو باز کن (یا دستور
  **`Router Models: Reload from Settings Sync`** رو اجرا کن) تا
  تغییرات فوری اعمال بشن.

## ❓ سوالات پرتکرار

<details>
<summary><b>کلیدهای API من کجا ذخیره می‌شن؟</b></summary>
<br>

توی حافظه امن داخلی وی‌‌اس‌کد — همون جایی که وی‌‌اس‌کد اسرار خودش رو نگه می‌داره.
هرگز توی تنظیمات یا فایل‌های پروژه‌ت ظاهر نمی‌شن.
</details>

<details>
<summary><b>مدل‌هام رو توی انتخاب‌گر چت نمی‌بینم</b></summary>
<br>

روی آیتم نوار وضعیت (پایین سمت چپ، که با «Router» شروع می‌شه) کلیک کن و
**Refresh** رو انتخاب کن، یا دستور `Router Models: Refresh Models` رو از
پالت دستورات اجرا کن. مطمئن هم شو که وی‌‌اس‌کدت به‌روزه (۱.۱۰۴ یا جدیدتر).
</details>

<details>
<summary><b>سرویس‌دهنده‌های محلی مثل Ollama کلید لازم دارن؟</b></summary>
<br>

نه — فقط فیلد کلید رو خالی بذار.
</details>

<details>
<summary><b>یکی از کلیدهام دیگه کار نمی‌کنه</b></summary>
<br>

افزونه کلیدهای خراب رو خودکار علامت‌گذاری می‌کنه و دیگه ازشون استفاده نمی‌کنه.
منوی نوار وضعیت رو باز کن تا وضعیت هر کلید رو ببینی، یا سرویس‌دهنده رو ویرایش
کن و کلید رو عوض کن. می‌تونی زمان‌بندی انتظار (cooldown) رو هم با یک کلیک پاک کنی.
</details>
